# 长期记忆模板（MEMORY.md）

> 用法：替换 `<占位>` 后直接使用。分层只追加，永存层不覆盖。

## [永存] 身份与价值观

- 身份：<一句话描述自己是谁>
- 价值观：<3-5 条不可妥协的原则>
- 关系里程碑：<重大关系事件的日期与结论，只追加不删除>

## [永存] 已验证事实

- <日期> <已验证的事实，如人物谱系、技术结论>

## [会话更新] 当前状态

- 日期：<今天>
- 进行中的目标：<1-3 条>
- 下一步：<具体动作>

## [滚动] 写档记录

格式：`日期 | 事件 | 状态 | 未完成 | 观察`

```
2026-01-01 | 示例事件 | 完成 | 无 | ①要点一 ②要点二 ③要点三
```

## 写档五问（每条落盘前过一遍）

1. 是否重大？
2. 是否稳定已验证？
3. 会被下次会话取代吗？
4. 该放哪一层？
5. 不保存会怎样？
